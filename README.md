## Delivery

Progress Demo (course Week 11): catalog/categories, stock, search/sort, guest cart, login with cart retention, orders, mock payment, invoice/PDF/email, delivery, ratings and approved comments. A design prototype alone does not meet the working-software demo requirements.

Final Demo (date TBA): all project requirements, including custom manager screens, wishlist/discounts, reports, cancellations, returns/refunds, live support with attachments, permissions and concurrency.

## Workflow

Track work in [Jira](https://watchstore.atlassian.net/jira/software/projects/SCRUM/boards/1/backlog).

Use one branch per task: `feature/SCRUM-43-product-api` or `docs/SCRUM-15-project-setup`. Open a Pull Request, get a teammate review, and merge after relevant checks pass. Keep passwords, secrets and generated files out of Git; track source code, migrations and tests. Add stack-specific ignore rules after the stack decision.
